### 3. 技術細節

- **動態多軌 Web Audio 增益調節架構**：
  - 每個聲景軌道在 `AmbientSoundscapeManager` 內部均擁有獨立的 `GainNode`（`trackGain`），連接至共用的 `masterGain`。
  - 混音器拉桿滑動時直接操作 `trackGain.gain.setValueAtTime(volume, audioCtx.currentTime)`，達到即時 0 延遲的音量平滑調整，且不同聲景之間完全不互相干擾。
- **智慧全域按鍵攔截與專注導航**：
  - `bindShortcuts()` 嚴謹識別 `document.activeElement`，當使用者在任務輸入框打字或撰寫 Tip 紙條時自動放行原生鍵盤事件。
  - 按下 `T` 鍵時除平滑滾動舞台視角至待辦清單外，自動調用 `.focus()` 啟用任務輸入框，方便雙手不離鍵盤直接追加專注待辦事項。
- **純前端心流領域分佈引擎**：
  - `studyStats.getCategoryBreakdown()` 具備歷史兼容性，舊版本無 `category` 欄位的 session 自動歸納至預設 `dev` 領域，確保使用者歷史專注數據完整無損。
  - 進度條透過 CSS 原生 `style="width: ${cat.percent}%; background: ${cat.color};"` 實現輕量、流暢的視覺反饋。

### 4. 遇到的問題與解決方案

- **立體聲音場瀏覽器相容性與降級**：Web Audio API 的 `createStereoPanner` 在極少數特殊環境中可能未支援。

  - _解法_：在 `poster-generator.js` 與 `main.js` 中加入 try/catch，當剪貼簿寫入失敗時自動退回並為使用者觸發高清 PNG 檔案下載，同時給予友善 Toast 提示。
- **面板堆疊衝突與排版空間**：在專注舞台底端，原本已有定時模式列與白噪音面板，新增專注意圖列後需妥善安排佈局。

### 4. 遇到的問題與解決方案

- **非打斷式雜念傾倒體驗**：番茄工作法強調當前計時器不應隨意被干擾打斷。

- **Markdown 批次任務多樣格式相容**：使用者從 Notion、Obsidian、GitHub 或純文字複製的待辦清單語法各異。
  - _解法_：正則表達式相容無前綴、無序標號（`-`、`*`、`+`）、有序數字（`1.`、`2)`）、核取方塊（`- [ ]`、`- [x]`），並自動萃取結尾或句中的目標番茄標記（如 `(3)`、`[2]` 或 `🍅 4`），容錯率極高。

### 4. 遇到的問題與解決方案

- **Paul Kellet 粉紅噪音純純代碼合成**：傳統白噪音高頻過刺，粉紅噪音具有自然界 1/f 的能量衰減特徵。
  - _解法_：使用 Paul Kellet 的 7-極點 IIR 濾波器遞迴公式在 AudioBuffer 內即時演算 4 秒立體聲緩衝區（循環播放），CPU 負載小於 2ms，音質均勻溫暖，不需載入任何額外音訊資源。
- **動態潮汐海浪自然呼吸頻率**：海浪潮起潮落若為單純白噪音會顯得機械死板。
  - _解法_：使用 Web Audio API 原生 OscillatorNode 配置 `0.08Hz` 超低頻正弦波 LFO，同時調變 BiquadFilterNode 的截止頻率（150Hz ~ 660Hz）與 GainNode 放大率（0.2 ~ 0.9），重現約 12.5 秒一次自然海浪拍岸與退潮節奏，與人體放鬆呼吸完美共振。
- **無伺服器跨裝置遷移隱私保護**：不同裝置的使用者往往想在新筆電或手機上繼續自己的番茄累積紀錄與清單。
  - _解法_：設計兼具雙軌模式的跨裝置遷移架構——離線模式下一鍵打包為 Base64 代碼，在新裝置貼上解析融合；若兩台裝置處於同一 P2P 房間，則透過 WebRTC DataChannel 點對點空中推播，完全不經任何後端伺服器儲存個資。

### 4. 遇到的問題與解決方案

- **3D 伴讀娃娃眼神追蹤與配件聯動**：公仔由頭部、身體、雙手與多款外掛配件（眼鏡、王冠、魔杖、睡覺貓咪）組成，若僅單獨旋轉頭部可能導致配件穿模或脫節。
  - _解法_：統一對伴讀娃娃的展示根群組（`this.doll`、`this.standee` 或 `this.generatedModel`）進行整體偏航與俯仰插值，讓全套配件與光影保持完美一體化；並在拖曳轉向期間將追蹤目標平滑歸零，保障使用者手勢優先。
- **音軌切換時爆音（Audio Clicks / Pops）與播放不連貫**：Web Audio 若直接執行 `stop()` 或瞬間切換 `gain.value` 會產生高頻截斷爆音；若切換場景預設時全數重置音軌，正在播放的相同音軌會被打斷重啟。
  - _解法_：音軌啟動與停止全面使用 `linearRampToValueAtTime` 進行 0.8 秒平滑線性過渡；在 `applyTrackMix()` 中建立智慧差異比較，同一音軌直接平滑調節音量，保留音訊源節點繼續運行。
- **無套件純原生 QR Code 演算法實作**：QR Code 規範包含位元流打包、Reed-Solomon 錯誤更正（GF(256) 多項式除法）、區塊交錯（Interleaving）、定位標記、定時圖樣、格式與版本資訊以及遮罩罰分計算，容易因為位元偏移導致手機鏡頭無法讀取。
  - _解法_：自寫輕量化 ISO/IEC 18004 Model 2 演算法，精確配置尋像圖形（7x7）、分隔線、定位圖樣、黑暗模組與格式資訊（BCH 碼 XOR `0x5412`），並實作 8 組遮罩罰分評估，配合 2x Retina Canvas 繪圖，實際測試手機鏡頭與常見掃描器皆可瞬間辨識。
