### 3. 技術細節

- **分頁標題動態同步機制**：
  - `FocusTimer` 的 `tick` 事件每秒更新 `timer.remaining`，`NotificationManager.formatTabTitle()` 以補零格式轉換剩餘分秒並加上 Emoji 視覺錨點（🍅 / ⏸️ / 🎉），不依賴外部輪詢，運算開銷微乎其微。
- **Web Notifications 與跨分頁喚醒**：
  - 利用 `new Notification(title, { body, icon, tag })` 發送系統級通知，指定 `tag: "pomodoro-complete"` 避免多重通知覆蓋疊加。
  - 通知物件註冊 `notification.onclick = () => { window.focus(); notification.close(); }`，確保使用者在瀏覽其他視窗時能一鍵喚回小木屋。
- **背景紙條智慧感知（Document Visibility API）**：
  - 僅在 `document.hidden === true` 時推播夥伴 Tip，若使用者正在觀看小木屋頁面，則只透過現有的流星動態與 Toast 提示，避免重複打擾。
