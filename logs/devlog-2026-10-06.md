### 3. 技術細節

- **純演算法 Web Audio 脈衝響應與空間殘響構建**：
  - 傳統 Web Audio `ConvolverNode` 往往依賴下載數百 KB 至數 MB 的真實空間 IR WAV 檔案。本專案透過 `createProceduralImpulseResponse(ctx, duration, decay)`，建立雙聲道 `AudioBuffer`，左右聲道分別填充帶隨機噪聲的指數衰減波形 `(Math.random() * 2 - 1) * Math.pow(1 - i / length, decay)`，在 0 外部網路請求、0 靜態資源負擔的情況下，提供自然溫潤的空間反射殘響，並透過乾濕並聯增益節點（Dry/Wet GainNodes）實現精確的連續混音。
- **伴讀好感度經驗防刷機制與平滑階層設計**：
  - 伴讀人偶摸摸操作採用指針軌跡拖曳觸發，為避免高頻率摸摸導致數秒內瞬間刷爆等級，透過 `lastAffinityInteractionTime` 設立 3 秒冷卻閥門（摸摸愛心粒子與咕嚕聲音效仍可暢快觸發，但經驗值以 3 秒為單位安全遞增），兼顧即時手感與里程碑成就感。
- **多維時序篩選與全時段日期跨度顯示**：
  - 當使用者在專注時序中篩選「近 7 天」、「近 30 天」或「全部」時，時序條目時間戳動態補上前綴 `MM-DD HH:mm`，確保跨日期的紀錄具備清晰可讀的時序脈絡，而在「今日」模式下則維持清爽簡潔的 `HH:mm`。

### 4. 遇到的問題與解決方案

- **單元測試原先假設 exportExecutiveMarkdownReport 固定輸出「心流復盤週報」**：
  - 在擴充 `exportExecutiveMarkdownReport` 支援 `filterOptions` 時，若傳入 `{}` 預設會計算為 `range: "today"`，導致舊有測試斷言標題預期「心流復盤週報」失敗。
  - _解法_：將 `filterOptions` 預設參數設為 `null`，並以 `hasFilter = Boolean(filterOptions && (filterOptions.range || filterOptions.category || filterOptions.rating))` 明確判定是否為自訂區間，既保留向後相容的預設「週報」模式，又完整支援多維度篩選報告匯出。

- **零頻寬 Web Audio P2P 合奏拓撲（Zero-Bandwidth Acoustic Ensemble）**：
  - 傳統音訊串流廣播（如 WebRTC MediaStream）需要極大上傳頻寬與轉碼運算，音質易壓縮且消耗行動數據。本模組僅在 DataChannel 傳遞純 JSON 混音元數據（約 200 Bytes），各端接收後調用本地 Web Audio API 節點動態合成白噪音波形與空間殘響，達到最高音質、0 頻寬負擔的同房音景共振。
- **音訊淡入淡出數值曲線與急停消音防爆音（Click-Free Audio Ducking）**：
  - 直接調整 `gain.value` 會在波形交界處產生數位爆音（Click/Pop）。透過 `gainNode.gain.cancelScheduledValues(now)` 與 `linearRampToValueAtTime(target, now + duration)`，在暫停時以 0.8 秒指數感線性衰減至 25% 底音，保留木屋陪伴氛圍感，同時在重新開始時計時無縫回復 100%，打造如專業廣播級的自動 Ducking 聽覺體驗。

### 4. 遇到的問題與解決方案

- **ESLint no-useless-assignment 靜態檢查警報**：
  - 在 `renderPosterCard` 中，原先以 `let qrCanvas = null;` 初始化，並在 `catch` 區塊中重複賦值 `qrCanvas = null;`，被 ESLint 標記為 `no-useless-assignment`。
  - _解法_：改為在 `try` 內生成局部 Canvas 後再指派給 `qrCanvas`，`catch` 區塊僅作為安靜降級註解，不再進行多餘賦值，順利通過代碼規範。
- **Vitest Mock 環境下 Canvas drawImage 未實作問題**：
  - 在單元測試中，Vitest 使用 JSDOM 模擬環境，其 `HTMLCanvasElement.prototype.getContext` 預設未提供 `drawImage` 方法，導致測試在傳入 `qrCanvas` 時引發 `drawImage is not a function`。
  - _解法_：在 `FocusPosterGenerator.generateSoundscapeCard` 內加入防禦性判斷 `if (qrCanvas && typeof ctx.drawImage === "function")`，並於單元測試 setup 中補齊 `drawImage: vi.fn()` 模擬，兼顧測試穩健性與瀏覽器原生行為。

- **多條件自適應語意加權演算法（Context-Aware Dialogue Distribution）**：

## Session 5: 伴讀玩偶微動作手勢儀、專注歷史單次回顧編輯與小木屋沉浸光暈氛圍系統

### 1. 任務概述

延續自習小木屋「100% 零外部音訊與圖像依賴、純 Web Audio API 聲學合成、極致沉浸與陪伴感」原則，本輪推進三項深度迭代與體驗優化功能：

1. **伴讀玩偶互動微動作手勢儀與招手點頭動畫音學（Companion Micro-Emotes: Wave, Nod & Cheer System）**：
   - 擴充 Three.js 伴讀玩偶骨骼與肢體動力學，實作 3 組專屬微動作手勢：
     - `triggerWave`：舉起單臂朝使用者熱情揮舞小手，頭部微傾伴隨瞇眼喜悅微笑。
     - `triggerNod`：頭部輕柔點頭 2~3 次，呈現肯定與默契關懷。
     - `triggerCheer`：雙臂高舉歡呼躍起，慶祝番茄鐘完成。
   - 伴隨 Web Audio API 純代碼合成聲學反饋：

### 3. 技術細節

- **多狀態肢體動力學與微手勢（Procedural Skeletal Emote Interpolation）**：
  - 在 3D 玩偶既有的待機呼吸（Idle Breathing）、專注打字輕顫（Focus Jiggle）、休息伸展（Resting Stretch）與 360° 歡慶空翻（Joy Spin）之外，引進微動作狀態機（Micro-Emote State Machine）。手勢動作以 `currentEmote` 封裝型別、開始時間戳、時長與朝向；渲染幀利用 `now - startTime` 算出演算法正弦波擺動曲線（Sinusoidal Oscillation），動作結束後自動恢復預設肢體角度與開眼凝視視線，保證動畫過渡自然流暢且不卡死。
- **純代碼 Web Audio 鐘琴與木琴和弦聲學合成**：
  - `playGreetingWave` 使用三個正弦波振盪器於 0ms、70ms、140ms 依序觸發 A5 (880Hz)、D6 (1174.66Hz)、G6 (1567.98Hz)，配合 12ms 快速淡入與長達 480ms 指數淡出，模擬真實鐘琴鈴鐺的空靈敲擊感。
  - `playAffirmativeNod` 使用三角波振盪器於 0ms 與 90ms 敲擊 D5 (587.33Hz) 與 G5 (783.99Hz)，音頻向下滑動 30% 呈現木質共振沉穩質感。
- **無縫事後回溯編輯與數據一致性**：
  - 專注完成時自動建立的時序記錄，使用者常有事後補登筆記或校正任務名稱的需求。透過 `StudyStatsManager.updateSession` 將欄位清洗與長度限制集中於資料模型層，前端更新後自動通知時序清單與草木標本圖鑑（Herbarium）重新渲染，確保單一真相來源（SSOT）。

- **純代碼 2x Retina 手作壓花書籤比例與分層幾何構圖**：
  - 採用長寬比約 1:2.16（邏輯 380×820 像素，物理 760×1640 像素）仿實體書籤規格，並將繪圖流程分為 8 個模組化圖層：背景微光與星點、外圍雙重飾邊、頂部懸掛絲線孔扣（Silk Cord Loop & Eyelet）、壓花標本凹面名牌（Cameo Plaque，繪製特大植物 Emoji、學名與花語）、出處採收銘牌（Provenance Plate，含編號 `#NW-{PLANT}-00N`）、旅人手寫題字（Personal Inscription，支援兩行自動斷行）、以及底部 NW 雙環火漆封印（Wax Seal Monogram）。
- **Web Audio API 60 秒平滑自動淡出演算法**：
  - 在 `setSleepTimer` 中，每秒計時器當剩餘秒數 `<= 60` 時，計算當前衰減比例 `fadeProgress = remainingSec / 60`，並以 `linearRampToValueAtTime(Math.max(0.0001, masterVolume * fadeProgress), audioCtx.currentTime + 0.95)` 排程硬體音量漸變。此做法確保在關閉前有極其平滑的自然淡出曲線，杜絕任何數位爆音（Audio Clicks/Pops），並於歸零時優雅呼叫 `stopAll(1.2)` 釋放音頻資源。
- **單一真相來源（SSOT）之多維度歷史時序即時交集過濾**：
  - `studyStats.getFilteredSessions` 將時間區間（今日/週/月/全部）、心流評級（全部/心流/穩定/熱身）、植物種類與關鍵字多維度過濾收斂於同一純函數內，避免分散判斷導致時序清單與統計摘要數字不一致。

### 3. 架構決策與反思

- **黑膠雙層合成機制的聲學物理仿真**：
  - 傳統簡單的帶通白噪音只能模擬均勻粉紅噪聲，缺少黑膠唱片旋轉時「唱針觸碰微小塵埃與壓模顆粒」的突發衝擊感（Transient Clicks）。
  - 本設計透過獨立的調度器，在時間軸上引入卜瓦松分佈（Poisson Process）的非週期衝擊波，搭配高 Q 值帶通濾波器與快速指數衰減，在維持 0 外部採樣的前提下，創造極具真實類比唱盤溫度的微爆音。
- **草木書籤禮物的安全去中心化流通**：
  - P2P 通訊不依賴任何外部伺服器資料庫，書籤禮物完全以具備完整學名與銘文的純文本 JSON 封包在 WebRTC DataChannel 之間直接點對點傳輸。
  - 透過 `isBookmarkGift` 嚴格限制 `plantKey` 長度、字元集與字串界限，杜絕 XSS 與原型污染風險。
- **目標達標的瞬態激勵體驗設計**：
  - 將里程碑完成檢測置於 `recordSession` 前後比對（`!prevGoal.completed && newGoal.completed`），確保每日前端僅在「跨越 100% 的那一刻」發動慶祝儀式，不會在重複刷新或後續專注時造成聲光疲勞。

### 4. 遭遇問題與解法

- **Lucide 圖標在打包時缺漏**：
  - 新增之黑膠唱針（`disc`）、目標圓環（`target`）與贈送禮物（`gift`）按鈕需確保於 `lucide` 模組中具名匯入並登錄至 `icons` 字典中，否則 `createIcons` 將無法正確渲染 SVG 圖標。
  - _解法_：於 `src/main.js` 補足 `Disc`, `Gift`, `Target` 的匯入與 `icons` 映射註冊。
- **SVG 圓環尺寸與周長計算精準度**：
  - 圓環半徑為 `r = 38`，其周長為 `2 * π * 38 ≈ 238.761`。
  - _解法_：將 `stroke-dasharray` 固定為 `238.76`，並依 `percent` 計算 `offset = circumference - (circumference * percent) / 100`，使圓環在各種縮放比例下皆精準銜接且無邊緣溢出縫隙。
