### 3. 技術細節

- **純演算法 Web Audio 脈衝響應與空間殘響構建**：
  - 傳統 Web Audio `ConvolverNode` 往往依賴下載數百 KB 至數 MB 的真實空間 IR WAV 檔案。本專案透過 `createProceduralImpulseResponse(ctx, duration, decay)`，建立雙聲道 `AudioBuffer`，左右聲道分別填充帶隨機噪聲的指數衰減波形 `(Math.random() * 2 - 1) * Math.pow(1 - i / length, decay)`，在 0 外部網路請求、0 靜態資源負擔的情況下，提供自然溫潤的空間反射殘響，並透過乾濕並聯增益節點（Dry/Wet GainNodes）實現精確的連續混音。
- **伴讀好感度經驗防刷機制與平滑階層設計**：
  - 伴讀人偶摸摸操作採用指針軌跡拖曳觸發，為避免高頻率摸摸導致數秒內瞬間刷爆等級，透過 `lastAffinityInteractionTime` 設立 3 秒冷卻閥門（摸摸愛心粒子與咕嚕聲音效仍可暢快觸發，但經驗值以 3 秒為單位安全遞增），兼顧即時手感與里程碑成就感。
- **多維時序篩選與全時段日期跨度顯示**：
  - 當使用者在專注時序中篩選「近 7 天」、「近 30 天」或「全部」時，時序條目時間戳動態補上前綴 `MM-DD HH:mm`，確保跨日期的紀錄具備清晰可讀的時序脈絡，而在「今日」模式下則維持清爽簡潔的 `HH:mm`。

### 4. 遇到的問題與解決方案

- **單元測試原先假設 exportExecutiveMarkdownReport 固定輸出「心流復盤週報」**：
  - 在擴充 `exportExecutiveMarkdownReport` 支援 `filterOptions` 時，若傳入 `{}` 預設會計算為 `range: "today"`，導致舊有測試斷言標題預期「心流復盤週報」失敗。
  - _解法_：將 `filterOptions` 預設參數設為 `null`，並以 `hasFilter = Boolean(filterOptions && (filterOptions.range || filterOptions.category || filterOptions.rating))` 明確判定是否為自訂區間，既保留向後相容的預設「週報」模式，又完整支援多維度篩選報告匯出。

### 3. 技術細節

- **Three.js 程序化心流光環幾何體掛載與代碼分割保全**：
  - 光環幾何體掛載於 `this.doll`（伴讀人偶主群組），當玩偶進行 3D 旋轉、頭部跟隨滑鼠視線擺動時，光環均能自然跟隨世界變換。
  - 在狀態層（`src/state/store.js`）定義 `AFFINITY_AURAS` 元數據，確保 `src/main.js` 能直接讀取光環設定並進行資料清洗，而毋需提前引入龐大的 Three.js 核心庫，精準維持 Vite 對動態加載 `doll-viewer.js` 的代碼分割（Code Splitting）優勢。
- **音景分享碼協議 2.0 之雙向向後相容架構**：
  - 1.0 版協議格式為 `{ n, t: { rain: 60 }, p: { rain: -0.2 } }`，2.0 版擴充可選的 `{ eq: { b, m, t }, rv: { p, w } }`。
  - `decodeSoundscapeCode` 在面對舊版代碼時自動將 `eq` 與 `reverb` 設為 `null`，不影響音軌播放；在面對 2.0 版代碼時則精準映射至母帶處理鏈路，並同步更新控制台上的所有滑桿與預設按鈕狀態。
- **自適應心流勢能多因子加權演算法**：
  - 單純看時間容易忽視節奏品質，單純看次數容易受極短時間扭曲。勢能演算法採用「時長基準分（0~~50）+ 輪數穩定分（0~~25）+ 心流深度加成（0~25）」三重加權公式，既鼓勵持續專注，又引導使用者誠實標記深度心流，使休憩建議更符合真實大腦耗能曲線。

### 4. 遇到的問題與解決方案

- **ESLint no-useless-assignment 規則警告**：
  - 在 `main.js` 與 `study-stats.js` 中，宣告變數時給予了預設初始值（如 `let auraToApply = "none";`、`let recommendedMinutes = 5;`），但在後續完整的 `if-else if-else` 邏輯分支中所有路徑皆會賦值，觸發了 ESLint 嚴格的無效賦值警告。
  - _解法_：將變數調整為無冗餘初始值的宣告（`let auraToApply;`、`let recommendedMinutes;`），消除多餘賦值操作，維持嚴格型別與代碼整潔。
