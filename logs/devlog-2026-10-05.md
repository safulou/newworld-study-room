- **去中心化 P2P 狀態安全過濾機制**：
  - 新增之夥伴意圖與狀態均經嚴格字串長度截斷（意圖 48 字元以內、暱稱 18 字元以內）與合法值白名單檢驗，避免惡意畸形資料注入與 XSS 隱患，完全遵循零伺服器與隱私保護原則。

### 4. 遇到的問題與解決方案

- **觸控裝置窗戶滑動頁面捲動衝突**：
  - 在行動端手指掠過 `#cabinWindow` 時若觸發原生頁面滾動，會導致微風手勢體驗不流暢。
  - _解法_：在 `touchmove` 事件中設定 `{ passive: true }` 保障滾動效能，同時計算相對 X 軸位移提供平滑微風回應，移開手指後（`touchend`）即時優雅復原。
- **拍立得主題切換即時重繪效能**：
  - 若在彈窗中切換主題時重複創建 DOM Canvas 元素可能引發介面微閃爍。
  - _解法_：複用 `currentPosterCanvas` 並使用 `elements.posterCanvasWrapper.replaceChildren(currentPosterCanvas)`，確保 60fps 無縫切換主題畫布。

- **URL-safe 聲景碼零依賴編解碼**：
  - 聲景分享碼使用 `TextEncoder` 序列化 JSON payload（包含預設名稱 `n`、各音軌音量 `t`、左右空間 Pan `p`），並以 `btoa` 轉成 Base64 後替換 `+` -> `-`、`/` -> `_`，並去除尾端 `=` 填塞，產生短小精悍的 URL-safe 共享代碼。在解碼時嚴格檢驗 `AMBIENT_SOUND_TYPES` 白名單，防禦未授權欄位與超界數值。
- **3D 伏案讀書與伸展人偶動力學模擬**：
  - 在 Three.js 姿態中，`focusing` 狀態時計算書本的擺放高度，將手臂旋轉角度 `leftArm.rotation.x` 與 `rightArm.rotation.x` 往前平移並朝內扣合，同時透過正弦震顫函數 `Math.sin(time * 12) * 0.03` 模擬專注抄寫時的指尖動態；頭部向下低頭俯視（`head.rotation.x += 0.22`），沉浸感十足。
