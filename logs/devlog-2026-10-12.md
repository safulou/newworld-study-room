### 3. 技術細節

- **多音軌空間方位加權平均向量（Acoustic Azimuth Weighted Pan）**：
  - 各音軌具有獨立聲相 $Pan_i \in [-1, 1]$ 與獨立音量 $Vol_i \in [0, 1]$。
  - 主導方位角計算公式：
    $$Pan_{dominant} = \frac{\sum (Pan_i \times Vol_i)}{\sum Vol_i}$$
  - 當無任何音軌發聲或總音量為 0 時，預設回歸正中 $0$。
- **人偶生動側耳姿態動力學（Acoustic Head Cocking & Yaw Tracking）**：
  - 偏角 $Yaw = -Pan_{dominant} \times 0.35$（因觀察者視角中，音軌在左邊需讓人偶朝其自身右側/觀察者左方偏轉）。
  - 側傾角 $Tilt = Pan_{dominant} \times 0.12$（模擬好奇傾聽時頭部向聲源方向側傾的自然人體工學）。
  - 透過原有的 `lerpFactor = 0.06` 平滑插值，避免音量瞬變時頭部抖動，轉頭過程柔和溫潤。
- **URL-Safe 2D 矩陣壓縮編碼（Base64 URL 2D Coordinate Encoding）**：
  - 在 JSON 封裝中使用簡短鍵值 `cd: { [track]: [x, y] }`，坐標數值四捨五入至小數點後兩位。
  - 搭配原有 Base64 URL-safe 轉換，維持極短的 URL 網址長度（< 150 字元），方便社群即時分享與二維碼印製。

### 3. 技術細節

- **大氣空氣吸收阻尼音響學模型（Atmospheric Acoustic Air Absorption）**：
  - 聲波在乾燥空氣中長距離傳輸時，高頻（> 4kHz）因氣體分子鬆弛作用（Molecular Relaxation）而衰減極為迅速，低頻則衰減相對微弱。
  - 本系統設計線性頻率對稱映射：
    $$f_{cutoff}(y) = 2600 + y \times 17400 \quad (y \in [0, 1])$$
  - 當發聲源位於遠處（$y=0$）時，高頻截止在 2,600 Hz，消除銳利雜音並營造遠方圍爐或林風的朦朧深邃氛圍；當發聲源貼近耳朵（$y=1$）時，截止頻率達到 20,000 Hz（全頻通帶），忠實保留細微擬真質感。
- **P2P 協議無痛向下相容性（P2P Protocol Graceful Fallback）**：
  - `sendSoundscapeSync` 協議載荷僅在 `coordinates` 存在時序列化鍵值，若遠端對等節點運行舊版客戶端，則自動忽略額外欄位，不影響原有的音量、EQ 與殘響同步。
- **流星祈願音階和弦矩陣（Celestial Chord Matrix）**：
  - 選用 D 大調升九/高八度空靈泛音（D6: 1174.66Hz, F#6: 1479.98Hz, A6: 1760.00Hz, D7: 2349.32Hz），以 $0.08\text{s}$ 等距階梯延遲觸發，各軌具備自然指數量級釋放（Exponential Release Ramp），創造出如流星拂過夜空的剔透晶瑩感。

   - 與「🦗 夏夜鳴蟬（`crickets`）」環境音軌自動連動：啟動鳴蟬時若天氣為預設窗景，自動帶入螢火蟲微光。

### 4. 遇到的問題與解決方案

- **放大鏡初始桌面平貼角度與人偶拾取姿態過渡**：
  - _問題_：放大鏡直接水平放置在桌面易與桌面幾何穿插，拾取時需要平滑過渡至右眼前方。
  - _解法_：在 `doll-viewer.js` 中將放大鏡放置於專屬微群組 `magnifierPivot`，給予桌面上傾斜初始角度（`-Math.PI/2 + 0.12, 0, -0.35`）；在觸發細察微動作時，使用 smoothstep 曲線協同人偶頭部俯角與右手位置，將透鏡精準平移至右眼右前方（X: 0.33, Y: 0.08, Z: 0.45），呈現高度逼真的求知細察姿態。
- **小蘑菇快速連點時的彈跳動畫中斷與 CSS 重流防護**：
  - _問題_：連續快速點擊小蘑菇時，若動畫 class 尚未結束，不會重新觸發彈跳。
  - _解法_：在點擊處理函式中先移除 `mushroom-bouncing` 類別，透過 `mushroom.offsetHeight` 強制觸發重流（reflow）後再重新新增類別，確保每一次點擊都能即時獲得彈跳反饋，並搭配 4 秒經驗防抖保護。

### 3. 技術亮點與架構決策

- **Convolver 後級殘響染色拓撲（Reverb Damping Filter Placement）**：
  - 染色濾波器必須放置在 Convolver 輸出與 `wetGain` 之間（`eqTreble -> convolver -> reverbDampingFilter -> wetGain -> masterSumGain`），若放置在 Convolver 前會改變進入空間的激勵源特徵，若放置在 Master 總線上則會破壞乾聲（Dry Path）保真度；串接於殘響專屬支路確保了空間尾韻吸收特性的純粹性與零副作用。
- **純 Web Audio 羊皮紙沙沙摩擦四相動態掃頻（Parchment Scratch Synthesis）**：
  - 運筆摩擦聲採用帶通噪聲濾波器（`Q = 4.2`），並以 4 段非線性時間斜率在 1700Hz 至 2800Hz 之間來回微幅掃頻，輔以極短隨機顫動與微小脈衝起伏，完美再現真實鵝毛筆尖在纖維羊皮紙上的粗糙摩擦音感。
- **羽毛筆動態姿態三相分解（Three-Phase Motion Decomposition）**：
  - $0 \sim 0.32$（沾墨相）：右手與筆身平移伸向墨水瓶口微向下探入，頭部向右下凝視。
  - $0.32 \sim 0.84$（揮毫相）：筆尖移至書桌前，頭部正前俯視，手腕以正弦複合頻率在紙面上進行三次草書揮毫，筆身伴隨書寫輕微俯仰。
  - $0.84 \sim 1.0$（收筆歸位相）：手腕抬起，羽毛筆平穩放回硯台右側，頭部與手臂回歸端正待機姿態。

### 3. 關鍵決策與技術反思

- **仰角濾波器拓撲定位（Elevation Filter Topology Placement）**：
  - 仰角濾波必須放置在距離低通濾波器（`distanceFilter`）之後、立體聲聲相器（`panner`）之前：`trackGain -> distanceFilter -> elevationFilter -> panner -> masterGain`。
  - 此拓撲確保了耳廓垂直頻響印記直接作用於單一音軌的原始聲學內容，不會干擾左右耳立體聲平衡，也不會影響後續早期反射或主殘響支路。
- **金屬簧片微音物理合成模型（Metallic Reed Physics Modeling）**：
  - 傳統合成八音盒常使用單一正弦波，容易顯得電子生硬。八音盒鋼簧物理振動時，除了基頻正弦波（帶微長衰減）外，具有特徵高頻非諧波分量（約 $2.756 \times f_0$），該分量衰減速度極快（約 50ms）。透過將兩組頻率以不同增益衰減曲線並行合成，能在純 Web Audio 環境下呈現極度清澈純淨、宛如實體金屬簧片彈撥的物理共鳴。
- **人偶與曲柄旋動微動作同步（Doll Arm & Crank Rotational Synchronization）**：
  - 發條曲柄在 3D 空間中沿 X 軸旋轉，人偶右手的肩部與腕部旋轉必須動態配合曲柄位置（正弦與餘弦微偏移），形成逼真擬真的握持轉動手感，而非僵硬的靜態機械臂。

### 4. 遇到的問題與解決方案

- **曲柄發條聲與八音盒琴音的銜接時序**：
  - _問題_：人偶轉動曲柄需時約 1.2 秒，若發條喀噠聲剛結束立即響起琴音，會有倉促感；若太晚響起，又會失去發條釋放與音樂奏響的因果連動。
  - _解法_：發條聲設定長度 1.2 秒（前急後緩），並於 950ms 處平滑銜接第一聲清脆的八音盒琴音，此時發條聲漸弱收尾，八音盒旋律自然流淌，視聽合一感極佳。
- **夏蟬點擊碰撞區域與花園其他物件重疊**：
  - _問題_：夏蟬依附於花園植物右側枝幹附近，若點擊區域過大，容易在點擊小蘑菇或花朵時造成誤觸。
  - _解法_：精確限制夏蟬 DOM 尺寸為 $24\text{px} \times 20\text{px}$，`position: absolute; right: 28px; bottom: 82px;`，並於點擊處理中使用 `e.target.closest("#gardenCicada")` 作優先級分流，各植物與生物互動完全互不干擾。

### 3. 關鍵決策與技術反思

- **打字機機械敲擊音雙振盪器空腔物理合成（Mechanical Striker & Cavity Dual-Oscillator Topology）**：
  - 傳統單一音訊脈衝難以表現機械打字機的厚實感。古董打字機的特徵在於「金屬撞針敲擊色帶」的極短高頻衝量（1600Hz $\to$ 750Hz 三角波，衰減約 28ms）與「橡膠滾軸與鑄鐵空腔」的低頻箱體共振（260Hz $\to$ 140Hz 正弦波，衰減約 42ms）。將兩者並行疊加並輔以微小隨機時間抖動，生成出極具年代感且悅耳舒適的機械打字 ASMR。
- **動態頭部運動雙耳自適應補償（Dynamic Pinna Yaw Head Tracking Compensation）**：
  - 當聽者向右轉頭（`dynamicHeadYaw > 0`）時，空間中的聲源相對於聽者耳道相當於向左偏轉（`headOffset = -dynamicHeadYaw`）。將此補償量直接注入 `getEffectiveTrackPan` 與 `calculateEffectiveCutoff`，使聲學舞台在滑鼠微移或傳感器轉向時，耳廓遮蔽（Head Shadowing）與雙耳時差（ITD）能平滑連動，完全不需沉重的空間多聲道卷積開銷。
- **人偶敲鍵與撥桿動作拆解（Typewriter Key Striking & Lever Return Phasing）**：
  - 打字動作分為兩階段：0~~2.2s 雙臂高頻交替快速下壓（`Math.sin(elapsed * 24)` 與 `Math.cos(elapsed * 24)`），模擬行雲流水的打字節奏；2.2s~~2.8s 右手向前伸展將撥桿往右推開 35°（`typewriterLever.rotation.z`），頭部微微向左目送滾軸回位，第 2.8 秒回正放鬆，整體微動作栩栩如生。

### 4. 遇到的問題與解決方案

- **花園微風花瓣飄舞軌跡與視窗縮放適配**：
  - _問題_：花園在不同螢幕寬度下有自適應寬度，若花瓣位移使用固定絕對像素，在極窄螢幕上可能超出花園卡片邊界。
  - _解法_：在 CSS 中為花瓣容器設定 `overflow: hidden; border-radius: inherit; pointer-events: none;`，並在 JS 生成時採用相對百分比搭配隨機振幅微調（`--startX`, `--swayX`, `--endX`），確保花瓣始終在花園盆栽上方輕盈舞動且不會破壞排版。
- **聲學畫布指針事件與音軌拖曳的優先級衝突**：
  - _問題_：當使用者在雷達畫布上拖曳音軌時，若同時觸發頭部動態偏角計算，可能導致拖曳過程聽感與聲相跳變。
  - _解法_：在 `pointermove` 事件處理中，先判斷 `if (draggingTrack) return;`，將拖曳音軌座標設定為最高優先級；僅在非拖曳狀態且啟用頭部追蹤時才更新 `dynamicHeadYaw`，保證操作穩定流暢。
